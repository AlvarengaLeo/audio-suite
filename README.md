# Majes de Sivar — Audio Suite

Suite profesional de audio impulsada por inteligencia artificial.

## Servicios

- **Audio Enhance** — Mejora de audio con DeepFilterNet y Resemble Enhance (denoising + super-resolución)
- **Audio Extract** — Extracción de audio desde video en calidad PCM 24-bit / 48kHz
- **Text-to-Audio** — Síntesis de voz neural con 18+ voces premium en 7 idiomas

## Tecnologías

- DeepFilterNet3 (denoising en tiempo real)
- Resemble Enhance (super-resolución SOTA)
- FFmpeg 8.0 (extracción de video)
- Edge TTS / Azure Cognitive Services (síntesis neural)
- Pedalboard (masterización de audio)
